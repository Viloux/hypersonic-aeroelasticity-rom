Parametric POD Aerodynamic Reduced-Order Modelling

Author: Elena Balmus

Research interests: Aerospace Engineering, Computational Mechanics, Reduced-Order Modelling, and Hypersonic Aeroelasticity.

Project Overview

This project establishes a reproducible numerical baseline for investigating parametric proper orthogonal decomposition (POD) applied to aerodynamic reduced-order modelling.

The long-term research objective is to investigate efficient aerodynamic ROMs coupled to low-order structural dynamics models, with a focus on aeroelastic stability prediction and model reliability.

Objectives

* Generate aerodynamic snapshots across selected operating parameters.
* Construct a reduced-order representation using singular value decomposition (SVD) and POD.
* Evaluate reconstruction accuracy using quantitative error metrics.
* Extend the framework towards parametric aerodynamic prediction.
* Investigate coupling with structural dynamics and stability analysis.

Tools

* Python
* NumPy
* Matplotlib
* SciPy
* Jupyter Notebook

Research Roadmap

1. Establish a reproducible POD baseline.
2. Develop a parametric aerodynamic ROM.
3. Couple aerodynamic loads to a low-order structural model.
4. Evaluate aeroelastic stability prediction.
5. Investigate prediction errors and reliability indicators.

Scope and Limitations

The initial numerical experiments are intended as foundational demonstrations. Synthetic aerodynamic data do not represent validated hypersonic CFD results or experimentally verified flutter predictions.

Further development will focus on benchmark validation, parameter generalisation, and stability-aware model assessment.

Reproducibility

The notebook and dependency list are provided to support transparent and repeatable numerical experiments.
